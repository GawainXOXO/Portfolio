# Portofolio Ryan

Next.js 16 + Tailwind CSS 4 + TypeScript. Dwibahasa (ID/EN), mode gelap/terang.

## Mengisi konten
Semua teks ada di `lib/data.ts` (cari tanda `TODO`). Teks antarmuka ada di `lib/i18n.tsx`.

## Menjalankan
```bash
npm install
npm run dev
```

## Deploy ke Vercel
Push ke GitHub, lalu di vercel.com pilih **Add New → Project → Import** repo ini. Tidak perlu environment variable.
